# Receipt2Books mobile app

React Native (Expo SDK 57, managed workflow) with Expo Router and TypeScript. TanStack Query is added in S1-T12.

## Current state

This is Expo's default starter app (Home and Explore tabs), with the Receipt2Books structure planned around it:

- `src/app/`: **routes** (Expo Router, every file is a screen). Currently the Expo starter screens.
- `planned-routes/`: placeholder route files for the real app (auth, tabs, receipt detail), each with TODOs.
  They live outside `src/app/` so they don't break the router while they're comment-only.
- `src/api/`, `src/auth/`, `src/types/`, `src/utils/`, and `src/components/` + `src/hooks/` files such as
  `receipt-card.tsx` or `use-receipts.ts`: placeholder modules with TODOs.
- Everything else in `src/components/`, `src/hooks/` and `src/constants/` is from the Expo starter.

## Run it

1. `npm install`
2. `npx expo start`, then scan the QR code with Expo Go on your phone.

## S1-T12: replace the starter with the Receipt2Books app

1. Delete the starter screens (`src/app/index.tsx`, `src/app/explore.tsx`) and the starter-only components
   (`app-tabs*`, `animated-icon*`, `hint-row`, `web-badge`, `external-link`, `ui/collapsible`) once nothing uses them.
   Keep `themed-text`, `themed-view`, `constants/theme.ts` and the theme hooks if you want them.
2. Move `planned-routes/*` into `src/app/` (replacing the starter `_layout.tsx`) and give each route a placeholder screen.
3. Install packages with `npx expo install` (it picks versions compatible with the Expo SDK):
   `@tanstack/react-query expo-secure-store` now; `expo-image-picker expo-image-manipulator` in S1-T17;
   `react-native-svg` + a chart library and `@react-native-community/datetimepicker` in Sprint 2.
4. Run `npx expo lint` once to set up ESLint (eslint-config-expo); add Prettier and `jest-expo` +
   `@testing-library/react-native` for tests in `__tests__/`.
5. Copy `.env.example` to `.env` and set `EXPO_PUBLIC_API_URL` to your PC's LAN IP
   (a phone can't reach `localhost` on your PC).

## Notes

- `AGENTS.md` and `.claude/settings.json` ship with the Expo template: guidance for AI coding tools
  (use `npx expo install`, check the versioned Expo docs).
- `expo-env.d.ts` is generated by Expo on first start and is git-ignored.
- Before finishing a task: `npx tsc --noEmit` and `npx expo lint`. `npx expo-doctor` checks dependency health.
